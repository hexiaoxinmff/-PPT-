# PPT Work Assistant

A generic, Chinese-first presentation and office prompt assistant for colleagues who prefer to describe work in everyday language.

## Includes

- Plain-language prompt routing and an 18-category prompt library.
- Three delivery modes: management decision, execution delivery, and external communication.
- Optional outline-first workflow.
- PPT diagnosis, aesthetic decision rules, visual craft guidance, and an anonymized visual casebook.
- Read-only PPTX preflight, structural diagnosis, and Windows drag-and-drop preflight entry.

## Use

1. Copy the `presentation-assistant` folder into a compatible skill directory, or load it through your AI workplace platform's skill mechanism.
2. Start with `presentation-assistant/同事体验说明.md` or `presentation-assistant/同事使用入口.md`.
3. Upload only materials you are permitted to process on the chosen platform.

## Local optional dependency

The read-only PPTX scripts use Python plus `python-pptx`:

```text
pip install python-pptx
```

## Privacy and boundaries

This public edition intentionally excludes real work materials, survey responses, generated deliverables, proprietary templates, third-party vendor source trees, and screenshots. It produces drafts and review checklists; it does not replace legal, financial, safety, approval, or target-software verification.
