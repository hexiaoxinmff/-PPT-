# 高级静态制作技法

先确定观众第一眼要看什么，第二眼要用哪条证据。每页优先选一项主技法，确有需要时再补辅助技法。用户模板、品牌及交付环境优先。下列技法可以单页调用，也可以在同一章节反复使用以增强对比。

## 从任务自动匹配

1. 根据同事的原话和资料推断受众、要达成的动作、交付媒介和证据形态。精致版式是默认交付标准；资料不全时先做好已知部分，缺失信息在对应页标注。
2. 先确定全稿的版式系统，再逐页按证据关系选主技法。大纲稿把关键页的页型写进结构；成稿把技法落实到版面、图表或讲述节拍；诊断稿给页码和改法。
3. 下表用来初选，再按页内实际关系调整。统一字体、色彩和网格，选择不同密度的页型，给关键页更明显的视觉重心。只有局部编辑需求时，以原稿样式和变更范围为准。

| 同事的任务 | 默认匹配 | 影响选型的要点 |
| --- | --- | --- |
| 给领导汇报、请业主决策 | S02、S09、S11、S17 | 先看要决定什么；数据对比可加 S12，只有可加总的增减归因才用 S16 |
| 做经营月报或竞品分析 | S04、S09、S12、S13 | 趋势用时间序列，两期差异考虑 S14，多地同口径比较考虑 S15 |
| 出活动策划、筹备与复盘稿 | S01、S19、S20、S24 | 现场布局或到场动线用 S21，开场与执行页的密度分别设计 |
| 做招商、品牌展示或合作提案 | S01、S05、S23、S24 | 有授权主图时强调场景或产品；需要现场逐步讲解时再按动效库安排 |
| 展示门头、景观、空间改造 | S05、S06、S07、S21 | 先定位现场关系，再展示局部和同口径对比，区分现状与示意 |
| 修改已有 PPT、优化一页 | 按页面症状查下表 | 例如文字分不清主次先用 S10，图表讲不出结论先用 S11、S12；指定页以外沿用原稿 |

交付前回看缩略图、重点分析页和至少一个章节衔接。发现重点不明、图表难读或版式节奏重复时，先调整信息层级和页型，再处理装饰。这里只在交付说明中按需解释设计选择，正式页面保留业务表述。

| 编号与技法 | 适用场景 | 制作动作与检查 |
| --- | --- | --- |
| S01 主视觉封面 | 招商、活动、空间提案 | 选一张与主题直接相关的主图，把标题放在空区。用局部暗化或纯色底保证反差；检查主图裁切和投影可读性 |
| S02 编辑式封面 | 高层决策、研究报告 | 标题分成主标题和短副标题，保留项目、日期等必要署名。以统一左轴和大块留白建立秩序 |
| S03 章节分隔 | 长稿换议题 | 用章节编号、短标题和一句导语保持系列感。按实际叙事节点插入，短稿可合并 |
| S04 大数字证据 | 单一指标足以支撑判断 | 数字、单位、期间与对照基线放在一起；脚注给出口径。检查大数字与文字结论一致 |
| S05 非对称图文 | 空间、产品、活动概念 | 让照片或图表占主区，说明对齐同一侧轴。用视觉重心配平，信息少时留白 |
| S06 局部放大与标注 | 门头、平面图、设计细节 | 保留全景定位，在侧边做局部裁切；用短引线标明真实位置。统一图片来源与方向 |
| S07 同口径改前改后 | 视觉改造、流程改进 | 固定视角、缩放、裁区或指标口径，标明现状、模拟、成品的状态。并排检查差异是否来自改动 |
| S08 拼图与留白 | 多张现场图或参考图 | 一张主图配少量辅图，同类图统一裁切。每图注释说明它证明了什么 |
| S09 报告网格 | 全套研究或经营汇报 | 固定边距、标题基线、主体区与页脚；用宽窄栏表达信息权重。使用母版或可复用版式时检查新增页继承效果 |
| S10 字体层级 | 内容有三层以上 | 用字号、字重与间距区分标题、事实、注释；双语数字和单位检查换行、对齐及替换字体 |
| S11 结论加证据 | 经营汇报、投资分析 | 上方一句有依据的结论，中间图表或对照，底部来源与限制。长材料移至备注或附录 |
| S12 排序横条 | 竞品、价格分布、类别比较 | 直接标注数值、保持共同尺度，按大小或有意义的业务顺序排序。突出一项，并保留样本口径 |
| S13 趋势与事件注释 | 月度经营、阶段观察 | 使用时间轴，标注真正影响解读的事件。检查时间间距、单位和缺测点，清楚区分同期变化与因果 |
| S14 斜率图或哑铃图 | 两期变化、成对对照 | 固定口径和比较组，直接标注起讫或差值。标签拥挤时减少比较组或改用表格 |
| S15 同尺度小多图 | 多区域、多品类比较 | 同类面板用统一单位、轴刻度和标题结构。若必须使用独立刻度，在图旁显式标注 |
| S16 瀑布图 | 财务或成本增减归因 | 先确认各项同期间、同单位、同基线且可加总。核对起点、增减项与终点；独立情景用并列图 |
| S17 决策矩阵 | 选方案、比竞品 | 行列固定对比口径，内容短句化，突出真正改变决定的差异。保留未测和不适用的不同标记 |
| S18 四象限定位 | 两维有比较意义 | 明示横纵轴含义与分界依据。定性定位标「示意」，数据定位需可追溯 |
| S19 流程或泳道 | 责任交接、审批、运营 | 只画关键步骤和交接，用泳道对应岗位；异常分支与主路径分开，检查箭头方向和责任归属 |
| S20 路线图与依赖 | 筹开、活动排期 | 用里程碑、必要前置条件和时间窗口搭建。计划、承诺、已完成用同一套状态规则 |
| S21 空间叠加 | 展位、动线、门店 | 保留授权底图，在其上以可编辑编号和形状标注；未测量的位置或距离按概念示意表达 |
| S22 可编辑图片蒙版 | 人物、商品、空间构图 | 有能力时用图片裁剪、容器或原生形状叠加；检查比例、裁区及重开后可编辑性 |
| S23 图层前后景 | 海报式封面、产品发布 | 背景、主对象、文字分层制作。只在需要时用遮罩增加空间感，确认标题与关键主体无遮挡 |
| S24 逐页镜头节奏 | 多页推介或路演 | 用总览、大画面、证据与行动页交替。重点比对可连续同版，章节转换用留白和密度变化建立节奏 |

交付时优先使用原生文本、表格、图表和需要编辑的形状。目标软件或工具没有对应能力时，选择可编辑的等效静态结构，并说明实际可编辑范围。缩略图检查整体节奏，按页检查对齐、裁切和字号，关键图表复核数据、单位和页脚来源。
