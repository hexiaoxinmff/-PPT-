# 信息关系的视觉表达

先问“信息之间是什么关系”，再选页型；以下是默认映射，不强制取代用户模板。

| 信息关系 | 优先表达 | 避免 |
| --- | --- | --- |
| 单一结论/主张 | 大标题 + 一句证据或一张主体视觉 | 把结论埋在长段文字或六个等权卡片中 |
| 两到四项比较 | 对照表、差异条、并列比较 | 没有比较维度的多列卡片 |
| 时间顺序/阶段 | 时间轴、阶段轨道、里程碑 | 把日期散落在多个段落 |
| 流程/协作 | 流程箭头、泳道、责任接口图 | 用一张大表混写动作、人员和时间 |
| 数量趋势 | 折线、柱状、斜率/增减标注 | 没有数据来源的“假图表” |
| 构成/优先级 | 排序条、占比图、优先矩阵 | 大量彩色饼图或未标注的比例 |
| 空间/动线 | 获准平面图、概念区块、动线箭头 | 把概念示意当作真实施工或现场图 |
| 风险/待决 | 决策矩阵、影响—紧急度、待确认清单 | 将未确认内容藏在页脚 |

图表必须使用用户提供或可核验的数据、清楚的单位和来源。没有可靠数据时，用定性结构图、待确认表或文字说明，不造数填图。
