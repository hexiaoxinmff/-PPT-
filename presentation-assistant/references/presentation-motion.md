# 页面切换与对象动画

页面切换控制页与页之间，对象动画控制页内元素出现、强调、退出或移动。先确定演讲节拍和交付媒介，再决定是否加入。现有稿按用户的修改范围处理，原动画在未要求重做的页面沿用。

根据任务自动判断动效。审批、传阅、兼用 PDF 的稿件优先保证静态阅读，放映版可在章节处用淡出。现场讲解有先后顺序的流程或数据时，关键页可采用 M06、M08 或 M09。活动开场或产品揭晓可试用 M04 或 M10。只有交付明确用于无人值守时才安排 M14。场景不明时，采用能直接阅读的完整页面。

| 编号与技法 | 任务信号 | 推荐制作 |
| --- | --- | --- |
| M01 无切换或淡出 | 经营汇报、打印兼用、密集分析 | 默认可用无切换；需要缓和换页时选淡出，约 0.3–0.5 秒作为试放起点 |
| M02 切出 | 章节硬切、现场节奏快 | 按演讲停顿直接换页，让下一页第一眼即有重点 |
| M03 擦除切换 | 下一页承接同方向时间线或空间动线 | 保持一致方向，先确认页面布局本身已暗示方向。使用短时长，试放后调整 |
| M04 平滑切换 | 封面到细节、地图到局部、产品拆解 | 复制相邻页并保留对应元素，再改变位置、大小或裁区。在目标软件确认对象匹配与运动；失败时用淡出加静态前后页 |
| M05 特殊切换 | 活动开场、表演节点、品牌片头 | 形状、溶解、涟漪、新闻快报、轮辐、百叶窗、梳理、抽出或分割只在主题确实匹配时选用。先试一处，按现场节奏定夺 |
| M06 分组出现 | 一页有多个讲述段落 | 用出现或淡入按论点分组，每组一次点击。标题、图表轴、单位和理解当前证据所需的内容共同可见 |
| M07 方向进入 | 流程、空间移动或分层结构 | 用短距离擦除、飞入或缓慢进入匹配信息方向；无空间含义时用出现。试放确认终点和阅读顺序 |
| M08 图示逐步搭建 | 流程、泳道、方案因果链 | 先放骨架，再按节点出现，节点及相关引线一起出现。末态完整，适合复制做静态版 |
| M09 数据分段讲解 | 引导观众看主要差别 | 先显示完整坐标与口径，再强调关键数据点或按组出现有可编辑条件的数据系列。可用有标签的高亮替代动画重绘 |
| M10 动态数字 | 活动大屏、单一指标揭晓 | 使用目标工具已验证的动态数字能力，设置最终值、单位、停留。精确财务数字优先直接出现 |
| M11 强调与退出 | 说明视线焦点或叠层替换 | 强调用一次颜色、透明度或轻微放大。退出只用于释放重叠区域，确保最后状态仍有完整结论 |
| M12 运动路径 | 路线演示、物体移动、产品机制 | 从真实起点到终点，轨迹、节点和对象同步；无法原生实现时用编号轨迹或分步静帧 |
| M13 动作控件 | 自助交互、选择章节 | 工具支持时用触发器或页内跳转，检查触发对象、返回入口和线性放映路径 |
| M14 定时换片 | 无人值守循环或展屏 | 仅按场景启用自动换片，按实际阅读时间设停留，检查首尾循环；人工讲解默认按点击换页 |

## 制作与验收

1. 字效、轮子、菱形、阶梯状等对象动画和特殊切换仅按实际软件界面选择。开始方式记录为单击、与上一动画同时或在上一动画之后。对象初始时长可从 0.2–0.5 秒试起，延迟按实播调整；默认无声音、无循环、无自动换片，演出和展屏按明确需求设定。
2. 动画页先列「页码、对象、效果、开始方式、顺序、时长、延迟、静态表达」，有工具能力时据此写入。平台不具备写入能力时提供逐页动画设置清单；保留可正常阅读的静态成稿。
3. 有条件时在 WPS 或 PowerPoint 的目标版本打开导出文件，用动画窗格核对实际对象与顺序，放映检查点击次数、遮挡、跳页和末态；另存、重开，复核效果仍保留。静态预检、PDF 和截图仅用于静态版式验收。
4. 交付说明分别写明页面切换、对象动画、静态降级、实际放映验收。提供 PDF 时检查静态页信息完整，避免把只能在放映后看到的内容当作静态稿已呈现。
