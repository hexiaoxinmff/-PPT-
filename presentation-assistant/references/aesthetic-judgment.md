# 审美判断与取舍

“更好看”不是多放装饰、换深色背景或把所有文字缩小。审美判断的目标是：让目标受众按预期顺序看懂，并让视觉表达增强而不是遮蔽结论。

## 先看什么

1. **整套叙事**：封面、开场、核心结论、证据、行动是否形成节奏；是否每一页都承担不同任务。
2. **页面目的**：每页能否用一句话说清“让观众知道/决定什么”。说不清时，先重组内容，不先调色。
3. **阅读层级**：标题、关键信息、支撑信息是否有明确先后；同等重要的信息是否被做成同样抢眼。
4. **表达匹配**：比较关系用比较；时间关系用时间轴；责任关系用分工；空间关系用获准的平面或概念示意。不要把所有信息塞进卡片。
5. **节奏与克制**：连续页面是否重复同一种结构；留白是否帮助聚焦；颜色、图标、图片、动效是否只服务重点。

## 取舍顺序

按影响从高到低处理，不建议一上来整套换皮：

1. **保留**：目标清楚、证据充分、版式已经服务阅读的页。
2. **删减**：不支撑该页结论的背景、装饰、重复说明和无依据素材。
3. **合并/拆分**：同一结论被两页重复时合并；一页存在两个以上互不相关结论时拆分。
4. **重组**：标题不能概括重点、阅读路径混乱、证据顺序反直觉时，调整标题、顺序和层级。
5. **换页型**：信息关系与表现形式不匹配时才换为比较、流程、矩阵、时间轴、空间示意或单一结论页。
6. **微调视觉**：最后才调整字体层级、间距、对齐、色彩、图片裁切和局部强调。

## 输出格式

```text
审美结论：黄——结构可用，但关键页的层级与节奏需要收敛。

必须先改
- P3：标题只是主题名，无法说明要表达的结论；改为结论式标题，并把两组无关信息拆开。

建议优化
- P5：连续使用三列卡片且文字量相近；保留最重要的一列，另外两列改为简短证据或移入附页。

可保留
- P2：结论、数据和下一步的阅读路径清楚；只需统一页边距。

修订授权：是否按“必须先改”项制作新副本？
```

## 常见误判

- 图片多、颜色多、动画多不等于高级；不能替代结论和证据。
- 字号小、元素多只提示风险；必须结合真实渲染、受众距离和页面用途判断。
- 同一母版不等于重复；相同的结论框架可以统一，信息关系不应机械复制。
- 视觉参考只用于判断风格和信息表达，不可复制其品牌、人物、数据、英文文案或未经许可的素材。

## 检查边界

真实页面优先：有渲染图时逐页审看；只有 PPTX 结构时，仅可输出“需要目视确认”的信号。不得把尚未渲染的文字提取、形状数量或算法阈值称为“审美已通过”。
