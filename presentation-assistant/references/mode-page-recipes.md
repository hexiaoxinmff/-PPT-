# 三种成稿模式的核心页型组合

这些是优先组合，不是强制页数。必须服从用户的资料、模板、受众、已确认事实和交付页数。

## 管理层决策稿

目标是让决策者快速知道“要决定什么、为什么、不同选择的影响是什么”。建议 6–10 页：

1. 封面：议题、汇报对象、日期/版本（只有用户提供时）。
2. 结论先行：本次希望推动的方向或需要拍板的事项。
3. 背景与现状：只呈现支撑决策的已知事实。
4. 方案/选项比较：选择标准、差异、利弊；没有真实选项就不伪造对比表。
5. 影响与条件：资源、风险、依赖、待确认项。
6. 决策请求与下一步：谁需要确认什么、确认后会发生什么。

资料较多时，增加“关键证据”或“实施路径”页；不要用执行细节淹没决策页。

## 执行落地稿

目标是让协作人员明白“谁在何时完成什么、依赖什么、哪里会卡住”。建议 8–15 页：

1. 封面和范围：项目/事项、交付边界、适用团队。
2. 目标与完成标准：已确认的目标，未确认目标单列。
3. 总体流程或里程碑：按时间或阶段组织。
4. 分工与接口：责任归属、协作对象、交接条件。
5. 资源和准备事项：只列已知或明确标为待确认的项目。
6. 风险、依赖和预案：按影响和处理动作表达。
7. 检查点与沟通机制：何时检查、由谁同步。
8. 待确认项与下一步。

可按任务增加现场动线、物料、传播协作或复盘页，但不得把概念示意写成已经确认的现场方案。

## 对外沟通稿

目标是让外部对象理解价值、愿意参与或继续沟通。建议 6–12 页：

1. 封面：主题、面向对象、品牌资产（仅在获准使用时）。
2. 受众问题与价值：对方为什么要关注。
3. 核心亮点：每页一个可由资料支撑的亮点。
4. 场景、内容或合作方式：清楚说明参与者会得到什么。
5. 可信依据：已提供的数据、案例、场景素材或来源；没有依据就不做“实力证明”。
6. 行动引导：下一步联系、报名或合作沟通方式。

对外稿不得泄露内部待决、预算、个人信息或未经确认的承诺；对来源和版权不清的图片，改用获准素材或占位说明。
