# WPS / PowerPoint 最小验收

仅在目标软件可正常使用且使用者授权时，基于副本完成以下检查；不要覆盖原稿，也不要关闭用户现有进程来解除文件锁定。

1. 打开副本，逐页快速检查字体替换、中文换行、表格行高、图片比例、图层遮挡和动画/母版提示。
2. 在一页普通文本框中改一段文字，在一张原生表格中改一个单元格；确认改动可见且未破坏版式。
3. 另存为新文件，关闭后重新打开该新文件，核对两项修改仍然保留。
4. 对投影风险较高的页面，以放映或适合的缩放比例检查标题、表格、脚注与颜色对比。

报告要分开写“已在目标软件验证”的对象和“只从文件结构推断”的对象。软件不可用、用户要求由同事后续体验，或任一步失败时，停止把兼容性称为通过，记录具体页面和表现。
