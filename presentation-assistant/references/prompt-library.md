# 通用办公提示词库 v0.1

模板用于把同事的自然语言整理为可执行任务。使用时替换方括号，删除不适用项；附件和真实资料优先于模板。除非使用者要求看到提示词，否则内部使用模板后直接开展工作。

## 01 文件阅读与信息提取

**适用**：读合同、通知、表格、会议纪要、扫描资料、图片文字。

```text
请阅读我提供的【文件/图片/表格】，目标是提取【需要的信息】并整理为【表格/清单/摘要】。
请逐项标明信息来源位置；无法辨认、缺失或前后矛盾的内容写“待确认”，不要猜测或补写。
输出按【字段/格式】排列，并在最后列出需要我补充或核对的事项。
```

## 02 会议记录 → 行动清单

**适用**：会议录音转写、微信聊天、零散记录。

```text
请把以下会议记录整理为行动清单。区分：已确定事项、待确认事项、行动项、负责人、截止时间和风险。
没有明确出现的负责人或日期写“待确认”，不要根据语气推断。先给一页摘要，再给可复制到表格的明细。
记录：
【粘贴记录或上传文件】
```

## 03 周报、月报、工作汇报

**适用**：日常工作记录、项目进展、领导汇报。

```text
请根据我提供的记录，整理一份面向【对象】的【周报/月报/专项汇报】。
按“已完成、进行中、问题与风险、需要协调、下一步”组织；每项只保留与决策或协作有关的信息。
未提供的数据、进度、负责人或日期标“待确认”。输出为【微信简版/Word提纲/PPT结构】。
资料：
【资料】
```

## 04 通知、函件与微信沟通

**适用**：通知、回复、催办、跟进、商户沟通。

```text
请起草一份发给【对象】的【通知/微信/邮件/函件】。事由是【已确认事实】，希望对方完成【动作】。
语气为【正式/友好/明确】，需包含【时间、地点、联系人、附件等】。
金额、期限、责任、合同引用等未提供内容请保留“待确认”占位，不新增承诺、处罚或结论。
先给发送版，再列出需我核对的信息。
```

## 05 合同条款提取与核对

**适用**：合同整理、版本比较、格式检查、制作前核对。

```text
请阅读我上传的【合同/模板/两个版本】，仅做条款提取与核对，不替代法律、业务或财务审核。
提取【主体、期限、费用、付款、交付、违约、附件等】并标注来源位置；比较版本时区分“明确差异、表述差异、需业务确认”。
不要判断合同有效性，不自行补写条款。输出为可复核表格和待确认清单。
```

## 06 合同或函件草拟

**适用**：基于已审批模板填充草稿。

```text
请以我提供的【已审批模板】为结构，草拟【合同/补充协议/函件】初稿。
只填写资料中已经确认的事实；缺少主体、金额、日期、期限、责任或签署信息时保留明确占位。
保留原模板的章节结构，并另列“待业务/法务确认”事项。不要把草稿表述成可直接签署的最终法律文件。
```

## 07 台账整理与数据清洗

**适用**：多表合并、字段规范、档案/资料台账。

```text
请整理我上传的表格/文件，目标是形成【台账名称】。
先保留原始记录，再建立统一字段：【字段列表】；识别重复、缺失、格式不一致和疑似异常，并逐项标出原因。
不要把空白当成零，不删除原始记录，不自动合并名称相似但无法确认的对象。输出清洗规则、结果表和待核对清单。
```

## 08 对账、费用、发票与报表核对

**适用**：费用核对、对账、开票资料检查、周/月报数据整理。

```text
请根据上传的【台账/账单/发票/报表】做【期间】的核对。
按“来源记录、应有数据、实际数据、差异、可能原因、待财务确认”输出；分别处理空白、零值、跨期、重复和无法匹配记录。
只计算资料可以支持的结果，不确认付款状态、不判断税务合规、不自行处理冲抵或调整。
```

## 09 巡检、保洁与现场问题记录

**适用**：巡检表、保洁照片、现场问题、整改跟进。

```text
请根据我提供的【巡检记录/照片/聊天记录】整理现场问题与整改跟进表。
字段包括：日期、区域/位置、可见问题、证据来源、责任对象、计划完成时间、状态、复核要求。
照片无法辨认或未提供的字段写“待确认”；不要仅凭照片判断卫生合格、整改完成或安全达标。需要时起草整改通知草稿。
```

## 10 设备、水电与运营数据汇总

**适用**：抄表、设备巡检、能耗数据、运营统计。

```text
请整理【期间】的【水电/设备/运营】记录，输出可核对的汇总表和异常清单。
先核实对象、表号/编号、周期、单位、倍率和计算规则；缺期、读数回退、表计更换、零基数或异常变化标“待核实”。
只有具备可比历史数据时才计算环比/同比，并注明口径和来源。
```

## 11 供应商资料与报价比较

**适用**：方案比选、采购参考、服务商资料整理。

```text
请比较我上传的【供应商资料/报价单/方案】。
先按同一维度整理：服务/产品范围、规格、价格与币种、税费、交付周期、售后、有效期、来源位置和缺失项。
不要把报价不同自动判定优劣，也不要替我做采购决定；请给出对比表、可追问问题和需负责人确认的选择条件。
```

## 12 活动策划与执行清单

**适用**：活动方案、排期、分工、复盘。

```text
请把以下活动想法/资料整理成【管理层决策稿/执行落地稿/对外沟通稿】。
先明确目标、受众、已知条件和待确认项，再形成结构；执行稿需包含里程碑、分工、依赖、风险和检查点。
不要虚构预算、人数、合作方、场地条件或已落实资源。需要 PPT 时按可编辑 PPT 流程制作并说明模板和预检范围。
资料：
【资料】
```

## 13 PPT 制作、修改与审美诊断

**适用**：方案汇报、活动提案、复盘、已有 PPT 改稿。

```text
请为【受众】制作/修改一份【用途】PPT，主题是【主题】。现有资料和模板是【资料】。
请选择合适的成稿模式，并先判断是否需要“先出结构再出成稿”。
如为改稿，请先【只诊断 / 直接在新副本修订】；视觉上重点检查标题层级、留白、图表表达和整套页面节奏。输出可编辑文件，并如实说明预检、渲染和目标软件验收范围。
```

## 14 生图、改图与效果图需求

**适用**：空间效果图、门头、活动主视觉、海报、图片局部修改。

```text
我需要【新生成 / 修改】一张图片，用于【用途】。主体是【对象】，需要保留/参考【上传图中的内容】；重点表现【风格、材质、光线、角度、比例、文字】。
未指定的区域请保持不变。先把我的需求整理成完整提示词并说明你理解的修改范围；我确认后再生成/改图。
画面中的文字、品牌标识和尺寸必须以我提供的准确内容为准；无法确认时留空或提示后期排版。
```

## 15 文案、方案与改写

**适用**：活动文案、宣传文案、项目方案、已有稿润色。

```text
请为【对象】写/改一份【文案类型】。背景和已确认事实是【资料】；希望读者完成【动作】；语气是【专业/亲切/简洁】；长度约【字数】。
先保证事实准确和表达清楚，再优化节奏。没有依据的数据、案例、承诺或宣传用语不要补写。
输出发送版，并附一版更简短/更正式的备选（如确有需要）。
```

## 16 调研、资料搜集与决策建议

**适用**：找案例、找供应商信息、研究工具、做方案参考。

```text
请调研【主题】，服务于【具体决策/交付】。优先使用【官方来源/一手资料/指定地区或时间范围】。
输出：结论摘要、可核验来源链接、关键信息对比、与当前任务的关联、尚未证实或需要我确认的部分。
不要把营销材料或搜索摘要当作事实；不确定信息明确标注。
```

## 17 通用任务分解

**适用**：任务还说不清、需要先理顺工作。

```text
我想处理【用自己的话描述的任务】。请先判断最终交付物、已有资料、关键风险和下一步。
只问最影响结果的一到两个问题；其他不确定内容先标“待确认”。然后给出一份可执行的步骤、所需资料清单和第一版草稿/模板，不要只给空泛建议。
```

## 18 提示词自我优化

**适用**：使用者想自己复制到豆包、ChatGPT、WPS AI 或其他工具。

```text
请把我的大白话需求改写成可直接复制给【工具名称】的提示词。
先补齐任务、上下文、资料、约束、输出格式和核对要求；不替我编造业务事实。先输出“你理解的任务”和“可复制提示词”，并标出我需要补充的最少信息。
原始需求：
【粘贴原话】
```
