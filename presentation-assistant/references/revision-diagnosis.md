# 改稿诊断与授权修订

## 两种入口

- **只诊断**：用户说“看看问题”“先诊断”“先别改”时，只读取文件并输出问题清单、优先级、页码和建议动作；不生成替代版本，不改写原稿。
- **授权修订**：用户明确说“直接修改”“按你的建议改”或指定页码与改法时，先说明计划改动，再另存新文件；未授权页面和对象尽量不动。

## 诊断输出

按优先级给出以下内容：

1. 文件与检查边界：是否可读取、是否做过静态预检、真实渲染/目标软件是否实际检查。
2. 逐页问题：页码、问题类型（信息密度、结构、重复、可读性、事实/风险、审美取舍）、影响和可执行改法。涉及视觉时按 `aesthetic-judgment.md` 标出保留、删减、合并、重组、换页型或微调的优先级。
3. 跨页问题：重复、叙事断层、结论与证据不一致、待确认事项分散。
4. 修订建议分级：必须先改 / 建议优化 / 可保留。
5. 授权问题：明确请用户选择“只出诊断”还是“按第 X 项开始修订”。

## 边界

- `scripts/diagnose_pptx.py` 只基于可提取的文字、字号、对象和重复块生成结构信号；图片文字、图表含义、动画、母版、真实视觉效果和业务事实需要额外人工或目标软件检查。
- 不把“文字多”机械判为错误；诊断应结合页面用途，并把纯视觉页标为“需要目视确认”而非失败。
- 没有用户授权，不覆盖原文件、上传文件或把真实案例并入技能包。
