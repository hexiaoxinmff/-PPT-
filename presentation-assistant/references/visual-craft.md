# 视觉工艺：建立可控的页面系统

视觉设计服务于阅读，而不是追逐复杂效果。先从用户的品牌素材、现有模板和交付场景中提取系统；没有资料时使用克制、可编辑的默认系统，并在交付中说明。

## 开工前的视觉方向卡

制作前用三到五句确定：

1. **气质**：例如理性清晰、温和亲近、专业稳重、轻快有参与感；必须与受众和用途对应。
2. **信息密度**：决策稿留白更多、结论更前置；执行稿信息更密但层级更严；对外稿可用更大视觉主体但不牺牲可信内容。
3. **视觉主体**：优先选择一种——数据、场景图片、产品/空间、人物、图标化关系或大标题。不要每页同时争夺主角。
4. **模板角色**：用户模板、可编辑底稿、视觉参考或通用版式。
5. **不可碰触的边界**：品牌色、字体、Logo、图片版权、敏感信息和已确认页面。

除非用户要求先确认视觉方向，否则直接据此制稿，并在交付摘要中说明即可。

## 字体、留白与对齐

- 一套稿通常只保留一个中文正文字体体系和一个英数字体系；依靠字号、字重、颜色和留白建立层级，不用多种花字制造层级。
- 每页应有清晰的标题、重点和支撑信息三层。标题是结论或问题，而不是重复章节名；正文避免把每句话都加粗或上色。
- 从模板或统一安全边距出发，对齐同一阅读轴；间距应有重复规律。局部紧凑可以表达关联，但不能让整页没有呼吸。
- 小字号只允许用于页码、来源、注释等次要信息；任何承载主结论、关键表格或行动项的文字必须以目标屏幕/投影阅读距离复核。

## 色彩与素材

- 颜色应承担角色：背景、正文、重点、状态和辅助，而不是每个模块一个颜色。重点色一页只突出少数关键信息。
- 图片要么承担证据或情绪主体，要么不放；避免无关装饰图、低清图、拉伸图和多张小图拼贴却没有阅读顺序。
- 图标只用于快速区分信息类型，统一线宽、圆角和视觉重量；不混用不同平台的图标风格。

## 页面节奏

在整套稿中有意识交替：结论页、证据页、关系页、行动页和必要的呼吸页。连续两页使用相同布局可以强化对比；连续多页相同卡片布局会降低记忆点，应至少改变主视觉、信息关系或留白比例。
